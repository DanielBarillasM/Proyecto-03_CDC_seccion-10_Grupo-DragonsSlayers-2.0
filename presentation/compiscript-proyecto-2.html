01 · Contexto

Validar el programa no basta: hay que representarlo

Después de lexer, parser y semántica, el compilador necesita una forma intermedia explícita para expresar cálculos, saltos, llamadas y almacenamiento.

Entrada

CST semánticamente válido

Solo se genera TAC cuando no existen errores léxicos, sintácticos ni semánticos.

Objetivo

Descomponer operaciones

Convertir expresiones y control de flujo en instrucciones simples con temporales y etiquetas.

Producto

IR inspeccionable

TAC textual, bloques, CFG, frames, layouts, métricas y exportaciones desde el IDE.

Diferencie error sintáctico de error semántico con un ejemplo breve.

03 · Pipeline

Cuatro fases, un resultado trazable

Cada fase conserva sus diagnósticos; TAC solo se ejecuta cuando las tres fases anteriores aceptan el programa.

Fuente .cpscaracteres
→
Lexertokens + errores
→
ParserCST de ANTLR
→
Semánticatipos + símbolos
→
TACIR + CFG + frames

Recuperación controlada

ANTLR continúa después de ciertos errores para informar más de un problema por archivo.

Sin cascadas falsas

Si lexer o parser fallan, la semántica queda marcada como omitida.

Resultado común

UI, CLI, exportaciones y pruebas consumen el mismo AnalyzeResult.

07 · Tabla de símbolos

Insertar, recuperar, actualizar y resolver ámbitos

Cada declaración conserva tipo, mutabilidad, inicialización, ubicación, referencias y captura por closures.

declare

Inserta localmente y detecta colisiones en el ámbito exacto.

resolve

Busca desde el ámbito actual hacia la raíz léxica.

updateSymbol

Actualiza tipo, estado, firmas y metadatos sin cambiar identidad.

enter / exit

Construye el árbol de bloques, funciones, clases y ciclos.

08 · Construcciones avanzadas

Funciones, closures, clases y herencia

FUNCIONES

Firmas posicionales

Valida cantidad y tipo de cada argumento, además del valor retornado.

CLOSURES

Capturas léxicas

Marca variables usadas desde una función anidada como captured.

CLASES

Identidad por ámbito

Clases homónimas pueden existir en ámbitos hermanos sin confundirse.

HERENCIA

Miembros transitivos

Campos y métodos se buscan en la clase y luego en sus ancestros.

function crearContador(): integer {
  let total: integer = 0;
  function incrementar() { total = total + 1; return total; }
  return incrementar();
}

12 · Representación intermedia

Instrucciones simples, almacenamiento explícito

TEMPORALES

Pool por frame

Los temporales se liberan y reutilizan sin reciclar valores que continúen vivos.

BLOQUES

CFG verificable

Saltos y condiciones apuntan a bloques existentes; return finaliza el flujo.

FRAMES

Offsets alineados

Parámetros, locales, capturas y temporales reciben tamaño y desplazamiento abstracto.

CLASES

Layouts heredables

Campos y métodos conservan offsets; cada clase posee un constructor TAC invocable y la hija encadena al padre antes de inicializar sus campos.
