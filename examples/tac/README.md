# Ejemplos de generación TAC

Los archivos válidos ejercitan expresiones, control de flujo, funciones, arreglos, clases y closures. El resultado incluye instrucciones, bloques básicos, aristas del grafo de flujo de control, temporales y registros de activación. Los casos de error comprueban que el código intermedio se omite cuando falla una fase anterior.

```bash
npm run cli -- examples/tac/13_programa_integral.cps --mode tac
```
